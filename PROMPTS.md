# Sparkwrit — ключевые промпты (Vibe Coding · День 1)

## 1. Спецификация продукта

```text
Ты — продакт и UX-редактор. Составь ТЗ для AI Micro-SaaS «Sparkwrit»:
генератор постов / резюме / сопроводительных писем с выбором тональности.

Нужно:
1) Целевая аудитория (3 сегмента)
2) 5 User Stories в формате «Как … я хочу … чтобы …»
3) Структура данных (TypeScript-интерфейсы)
4) MVP-скоуп на 2 дня + что НЕ делаем
5) Критерии приёмки для деплоя на Vercel

Пиши кратко, списками, без воды.
```

## 2. UI / визуальный язык

```text
Спроектируй UI для Sparkwrit (Next.js + Tailwind).

Бренд: Sparkwrit — AI writing studio.
Визуал: светлый cool paper фон, глубокий teal бренд, оранжевый акцент.
Шрифты: Unbounded (display) + Manrope (body), с кириллицей.
Не используй: purple gradients, cream+terracotta, Inter/Roboto, dark mode по умолчанию, карточки-статы в hero.

Экраны:
- бренд + один заголовок + короткий саппорт
- форма: тип контента, тон, тема, аудитория
- панель результата + копирование
- история в localStorage

Сделай адаптив mobile-first.
```

## 3. API-роут генерации

```text
Напиши Next.js App Router API route POST /api/generate.

Вход: { type, tone, topic, audience?, extra? }
Валидация длины topic.
Если нет OPENAI_API_KEY — верни качественный demo-текст (не ошибку).
Если ключ есть — вызови OpenAI chat completions (gpt-4o-mini), ключ только на сервере.
Верни { result, mode: "demo" | "openai" }.
Обработай 400/500/502 и пустой ответ модели.
```

## 4. Итерация после багов

```text
В консоли нет ошибок, но toast не закрывается / история не сохраняется.
Проверь: useEffect зависимости, JSON.parse guard, slice(0,30), SSR-safe localStorage.
Исправь минимальным диффом, не переписывай весь компонент.
```

```text
Напиши README для стажёрского MVP: стек, локальный запуск, .env, демо-режим,
деплой на Vercel по шагам, что показать на 5-минутном live demo.
```
